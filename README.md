# مونتير — ريل جاهز من فيديو كلامك

من **دار الإبداع للحلول البرمجية / Dar Al-Ibdaa for Software Solutions**.

تطبيق ويب (PWA) يفتح من الجوال: ترفع فيديو تتكلم فيه للكاميرا، فيحذف السكتات ويكتب كلامك، تراجع الكلام وتحذف ما لا تريده، ثم يطلّع ريل 1080×1920 بكابشن عربي بتوقيت كل كلمة وخاتمة بهوية العيادة وصوت مضبوط على ‎-14 LUFS.

## كيف يعمل

1. **الرفع:** من الجوال، والتطبيق يحفظ الفيديو على الخادم.
2. **التحليل (2–4 دقائق):** حذف السكتات، كتابة الكلام، تطبيق قاموس العيادة، وتعليم الجمل المشكوك فيها:
   - جمل يكتبها Whisper من عنده مثل «ترجمة نانسي قنقر» تُعلَّم للحذف.
   - الجملة التي أعدتها مباشرة بعدها تُعلَّم للحذف.
3. **مراجعتك:** تصحح الكلمات وتحذف الجمل. التصحيح الذي يتكرر مرتين يحفظه التطبيق في قاموس العيادة ويطبّقه تلقائياً بعدها.
4. **الإنتاج (نحو 5 دقائق لريل دقيقة):** الكابشن، القص والزوم، الرسم، الخاتمة، ضبط الصوت. ثم تنزّل الريل.

## النشر على CranL

1. في لوحة CranL: **New Application** واختر هذا المستودع. يقرأ CranL ملف `Dockerfile` تلقائياً.
2. **الخطة:** Pro (4 جيجا ذاكرة و4 أنوية). جرّبنا التطبيق بحدود 4 جيجا فأنتج ريل الفينير بذروة نحو 1.2 جيجا.
3. **المنفذ (Port):** ‎8080.
4. **قرص دائم (Volume):** اربطه على المسار `/app/data`. هنا تُحفظ الفيديوهات والهوية والقاموس، وبدونه تضيع مع كل نشر جديد.
5. **المتغيرات:** أضف `MONTEER_PASSWORD` و`GROQ_API_KEY` (الجدول تحت). بدون مفتاح Groq لن تعمل الكتابة على CranL، لأن الصورة لا تحتوي Whisper المحلي حتى تبقى خفيفة.

## التشغيل على خادم (VPS)

يكفيه خادم بـ 4 جيجا ذاكرة مع Groq، ونظام Ubuntu مع Docker.

```bash
docker build -t monteer .
docker run -d --name monteer -p 80:8080 \
  -e MONTEER_PASSWORD='كلمة-سر-قوية' \
  -e GROQ_API_KEY='مفتاحك من console.groq.com' \
  -v monteer-data:/app/data \
  --restart unless-stopped monteer
```

افتح عنوان الخادم من الجوال، ثم من قائمة المتصفح اختر **«إضافة إلى الشاشة الرئيسية»** فيصير تطبيقاً. ادخل **الإعدادات** واكتب كلمة المرور مرة واحدة.

### المتغيرات

| المتغير | المعنى |
|---|---|
| `MONTEER_PASSWORD` | كلمة مرور التطبيق. بدونها يفتح لأي أحد يعرف العنوان |
| `GROQ_API_KEY` | الكتابة عبر Groq بنموذج Whisper large-v3 (الأدق). **ضروري في صورة Docker.** الكتابة المحلية تحتاج تثبيت `requirements-local-whisper.txt` وخادماً بـ 8 جيجا |
| `MONTEER_LOCAL_MODEL` | نموذج الكتابة المحلي (الافتراضي `turbo`). النموذج `large-v3` يحتاج أكثر من 8 جيجا ذاكرة |
| `MONTEER_LOWMEM` | قص الفيديو مقطعاً مقطعاً (مفعّل في Docker): ذروة ~330 ميغا بدل ~3.4 جيجا |
| `MONTEER_KEEP_DAYS` | بعد كم يوم تُحذف الفيديوهات من الخادم (الافتراضي 30، لخصوصية المرضى) |

## تشغيل بدون Docker (للتجربة)

```bash
sudo apt install ffmpeg chromium nodejs npm
pip install -r requirements.txt
pip install -r requirements-local-whisper.txt   # اختياري: كتابة محلية بدون Groq
cd engine && npm install && cd ..
cd server && MONTEER_PASSWORD=1234 uvicorn app:app --host 0.0.0.0 --port 8080
```

## الملفات

| المسار | ما فيه |
|---|---|
| `server/app.py` | الخادم: الرفع، طابور المهام، الهوية، تنزيل الفيديو |
| `server/pipeline.py` | سلسلة الإنتاج، والقاموس الذي يتعلم |
| `server/transcribe.py` | الكتابة: Groq أو محلي |
| `web/` | واجهة الجوال (عربية، خط كبير، تعمل كتطبيق) |
| `seed/brand/` | هوية سوران الجاهزة (تُنسخ للقرص الدائم أول تشغيل): الشعار، الألوان، رقم الحجز، القاموس |
| `engine/` | محرّك video-ad-editor (MIT) — انظر `NOTICE.md` |

## ما نعرفه من الاختبار (26 نوفمبر 2026)

- **على فيديو الفينير (74.6 ثانية):** الكتابة المحلية بنموذج turbo احتاجت تصحيح نحو 25٪ من الكلمات، وقاموس سوران صحّح 14 كلمة منها تلقائياً.
- **قائمة المصطلحات مضرة:** تمرير قائمة مصطلحات لـ Whisper دفع الكتابة نحو الفصحى وأضاف جملاً لم تُقل، فأزلناها.
- **يبقى للتجربة:** Groq بنموذج large-v3 على فيديوهات عراقية، والهدف أقل من 10٪ تصحيح.

## غير موجود في هذه النسخة

- رفع يستأنف لو انقطع النت (حالياً يعاد الرفع من البداية).
- رسوم توضيحية تلقائية أثناء الكلام. هذه تُصمَّم يدوياً لكل فيديو حالياً.
- أكثر من عيادة على نفس الخادم.
